# SOUL CANTINA

Single-page website for the funk & soul band SOUL CANTINA, served via GitHub Pages at <https://soulcantina.de>.

- `index.html` – the whole site (inline CSS/JS, no build step, no external requests)
- `assets/img/` – logo and web-sized photos; the full-resolution originals live in one folder per event (e.g. `assets/img/altstadtfest_2026/`, `assets/img/Jazzfest_2023/`), web sizes are named `<event>-<photo>-<width>x<height>.jpg`

Open `index.html` locally in a browser to preview.
